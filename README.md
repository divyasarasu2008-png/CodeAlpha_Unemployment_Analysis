#  Unemployment Analysis in India using Python

##  Overview
This project presents a comprehensive analysis of unemployment trends in India using Python. It focuses on understanding how unemployment rates vary across states and over time, with special emphasis on the impact of the Covid-19 pandemic.

---

##  Objectives
- Analyze unemployment rate data across Indian states  
- Perform data cleaning and preprocessing  
- Explore trends using data visualization techniques  
- Evaluate the impact of Covid-19 on unemployment  
- Identify patterns and relationships in the dataset  
- Provide insights to support economic decision-making  

---

## Technologies Used
- Python  
- Pandas  
- NumPy  
- Matplotlib  
- Seaborn  
- Google Colab / Jupyter Notebook  

---

##  Dataset Information
- Source: Kaggle  
- Dataset: *Unemployment in India*  
- Features include:
  - State/Region  
  - Date (Monthly data)  
  - Unemployment Rate (%)  
  - Estimated Employed Population  
  - Labour Participation Rate (%)  

---

##  Data Preprocessing
- Handled missing values by removing incomplete records  
- Converted date column into datetime format  
- Renamed columns for clarity and consistency  
- Cleaned column names to remove unwanted spaces  

---

##  Exploratory Data Analysis

### State-wise Analysis
- Calculated average unemployment rate for each state  
- Identified top states with highest unemployment  

###  Trend Analysis
- Visualized unemployment rate over time  
- Observed fluctuations and patterns in monthly data  

###  Covid-19 Impact
- Compared unemployment rates before and during Covid-19  
- Observed a significant increase during the pandemic period  

###  Relationship Analysis
- Analyzed relationship between labour participation and unemployment  
- Used scatter plots and correlation heatmaps  

---

##  Key Insights
- Unemployment rates increased sharply during the Covid-19 period  
- Some states consistently reported higher unemployment levels  
- There are clear fluctuations in unemployment trends over time  
- Labour participation rate shows a noticeable relationship with unemployment  
- These findings highlight important economic patterns  

---

## Conclusion
The analysis reveals the significant impact of Covid-19 on unemployment in India. It also highlights regional disparities and time-based variations. These insights can help policymakers and analysts make informed decisions.
